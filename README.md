# Video editing workflows

This repository contains the existing agent skills under `.agents/skills/` and a reusable production example:

- **[Business Reel workflow](examples/business-reel/README.md)** — the scripts and lessons from a 54.5-second video, combining FilmCraft editing and sound, HyperFrames animation and captions, and a PhotoCraft cover. Includes setup instructions for another computer.

The example contains source code and original script content. Install the creative applications separately; large media files, application binaries and local logs are not included.
